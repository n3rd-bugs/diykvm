DIY PiKVM — API guide for Claude & other agents

A KVM-over-IP appliance: drive the target's keyboard/mouse, watch its screen, manage a virtual USB drive (an EFI System Partition), and talk to a serial console — all over HTTP/WebSocket. LAN-only.

1. Authentication

Humans log in at /login (session cookie). Agents use the API key. Get it by exchanging credentials once:

curl -s -X POST http://<pi>:8000/api/login \
     -d username=admin -d password=YOURPASS
# -> {"api_key":"<KEY>"}

Then send the key on every request — HTTP header X-API-Key: <KEY> (or Authorization: Bearer <KEY>); for WebSockets add ?token=<KEY> to the URL.

2. Input — keyboard & mouse WS /ws

Connect to ws://<pi>:8000/ws?token=<KEY> and send JSON messages:

MessageEffect
{"t":"kd","code":"KeyA"}key down (code = JS KeyboardEvent.code)
{"t":"ku","code":"KeyA"}key up
{"t":"mm","x":0.5,"y":0.5}absolute move — x,y normalized 0..1 over the target's primary display
{"t":"mr","dx":10,"dy":-4}relative move (trackpad), signed −127..127
{"t":"mb","button":0,"down":true}button 0=left 1=middle 2=right (JS MouseEvent.button)
{"t":"mw","dy":1}wheel (±1)
{"t":"reset"}release all keys & buttons

Keys: use KeyboardEvent.code values — letters KeyA..KeyZ, digits Digit0..Digit9, Enter Escape Backspace Tab Space, F1..F12, Arrow{Up,Down,Left,Right}, Home End PageUp PageDown Insert Delete, modifiers ControlLeft ShiftLeft AltLeft MetaLeft (and the Right variants), punctuation Minus Equal BracketLeft BracketRight Backslash Semicolon Quote Backquote Comma Period Slash. To type a capital "A": kd ShiftLeft, kd KeyA, ku KeyA, ku ShiftLeft.

Example (Python)

import asyncio, json, websockets
async def type_hello(pi, key):
    async with websockets.connect(f"ws://{pi}:8000/ws?token={key}") as ws:
        for c in ["KeyH","KeyI"]:
            await ws.send(json.dumps({"t":"kd","code":c}))
            await ws.send(json.dumps({"t":"ku","code":c}))
        await ws.send(json.dumps({"t":"mm","x":0.5,"y":0.5}))   # cursor to screen center
asyncio.run(type_hello("192.168.1.120","<KEY>"))

3. Screen GET /snapshot GET /stream

GET /snapshotsingle JPEG of the target screen right now
GET /streamlive MJPEG (multipart/x-mixed-replace)
curl -s -H "X-API-Key: <KEY>" http://<pi>:8000/snapshot -o screen.jpg

4. Virtual USB drive / EFI boot media /api/msd/*

The target sees a removable USB disk (a GPT disk with a FAT32 EFI System Partition). The drive is either attached to the target or mounted on the Pi for editing — never both.

EndpointDoes
GET /api/msd/status{state, attached, editing, can_edit, image_size}
POST /api/msd/detacheject from target, mount the ESP on the Pi (enables file ops)
POST /api/msd/attachunmount on Pi, hand the disk back to the target
GET /api/msd/ls?path=list a directory (only while editing)
POST /api/msd/upload?path=multipart file=@… upload
GET /api/msd/download?path=download a file
POST /api/msd/mkdir?path= · DELETE /api/msd/rm?path=make / remove
# put a UEFI bootloader on the ESP, then boot the target from it
curl -s -X POST -H "X-API-Key: <KEY>" http://<pi>:8000/api/msd/detach
curl -s -H "X-API-Key: <KEY>" -F file=@BOOTX64.EFI \
     "http://<pi>:8000/api/msd/upload?path=EFI/BOOT"
curl -s -X POST -H "X-API-Key: <KEY>" http://<pi>:8000/api/msd/attach

5. Serial console /api/serial/ports WS /ws/serial

GET /api/serial/portslist serial ports: {ports:[{device,desc,hwid}]}
WS /ws/serial?device=/dev/ttyUSB0&baud=115200&token=<KEY> bidirectional bytes: text you send is written to the port; data read from the port is sent to you
import asyncio, websockets
async def console(pi, key, dev):
    url=f"ws://{pi}:8000/ws/serial?device={dev}&baud=115200&token={key}"
    async with websockets.connect(url) as ws:
        await ws.send("\r")                 # nudge the prompt
        async for line in ws: print(line, end="")
asyncio.run(console("192.168.1.120","<KEY>","/dev/ttyUSB0"))

6. Notes

  • The mouse maps to the target's primary display (absolute) — use relative mr for multi-monitor targets.
  • Rotate the API key by re-running setup_auth.py on the Pi.
  • Everything is LAN-only; there is no rate limiting — don't expose port 8000 to the internet without a VPN.
